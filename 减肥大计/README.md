# 减脂小屋

双人私用的本地减脂记录应用。

## 打开方式

双击 `index.html` 即可使用。

如果想像手机 App 一样用：

- 电脑或手机浏览器打开后，点页面右上角“安装 App”
- 如果浏览器没有弹出安装，先用浏览器菜单选择“添加到主屏幕”
- 真正离线缓存和一键安装需要部署到一个网址，直接用 `file://` 打开时浏览器会限制部分 PWA 能力

## 这一版包含

- 两个人独立档案：小基数 / 大基数、身高、当前体重、目标体重、日摄入目标
- 默认成员：小白、小鸡毛
- 每日记录：体重、步数、运动分钟、饮水量、摄入量、睡眠时长、心情、备注
- 每日步数目标：8000 步
- 自动本地保存：数据保存在当前浏览器里
- 可玩化总览：双人进度、今日任务、七日路线、连续记录、徽章墙、互相鼓励
- BMI 展示：根据各自身高体重自动计算
- 趋势总览：最近 14 天双人体重趋势、本周双人均重
- 冰箱食材：添加剩余食材后生成一周两人份减脂菜单
- 食谱限制：不使用奶制品，不安排生沙拉，蔬菜默认熟吃
- 烹饪说明：每餐都带简单做法
- 同步中心：Apple Watch / Samsung Watch 同步入口、配对码、手动同步包导入导出
- 数据导出：右上角下载按钮可导出 JSON 备份
