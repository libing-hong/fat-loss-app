# 减脂小屋

小白和小鸡毛的双人私用减脂记录 App。

网址：<https://libing-hong.github.io/fat-loss-app/>

## 手机安装

这类网页 App 在手机上通常不是“下载 APK/IPA”，而是“添加到主屏幕”。

- iPhone：请用 Safari 打开网址，点底部分享按钮，选择“添加到主屏幕”。
- Samsung / Android：请用 Chrome 或 Samsung Internet 打开网址，点右上角菜单，选择“安装应用”或“添加到主屏幕”。
- 不建议在微信、Instagram、邮箱内置浏览器里安装，它们经常不显示安装入口。

## 这次优化

- 手机端改成底部固定导航，更像 App。
- 所有可点击按钮加大、加粗、增强边框和颜色。
- 徽章点亮后会出现勾号、金色背景和更明显的“已点亮”。
- “安装 App”按钮会弹出手机安装步骤，不再只给一句提示。

## 功能

- 双人档案、身高、体重、BMI
- 每日记录：体重、步数、运动、饮水、摄入、睡眠、心情
- 每日 8000 步目标
- 双人挑战、任务、路线、徽章、互相鼓励
- 两人份减脂菜单
- 不使用奶制品，不安排生沙拉，蔬菜默认熟吃
- 每餐带烹饪做法
- Apple Watch / Samsung Watch 同步规划和手动同步包
